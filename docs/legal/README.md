# Legal

The documents behind Archie's legal pages. Each file here is the single source: the site renders it at `/legal/<name>` at build time, so the page and this repository can't disagree.

| Document | Page | What it covers |
|----------|------|----------------|
| [Privacy policy](privacy.md) | `/legal/privacy` (also `/privacy`) | What Archie processes, where it goes, what is stored, and your choices |
| [Terms of use](terms.md) | `/legal/terms` (also `/terms`) | Using the hosted demo: acceptable use, AI and simulator limits, no warranty |
| [Third-party services and open-source notices](third-parties.md) | `/legal/third-parties` | The services a request can reach, and the open-source software Archie is built on |
| [Accessibility statement](accessibility.md) | `/legal/accessibility` | The standard Archie aims for, how it is tested, and known limitations |

These are good-faith documents written for an open-source project and its free public demo. They have **not** been reviewed by a lawyer. Changes are made through pull requests like any other change, so the git history is the change log.
